## 🎨 Características de la Web

1. **Fondo Global en Video Dinámico:**
   - Reproducción fluida y optimizada de `img/camiseta.mp4` en todo el sitio con overlay de diseño institucional.
2. **Escudo Oficial en 3D (`escudvector.png`):**
   - Marco tridimensional con física de inclinación (parallax) y relieve con bordado dinámico interactivo al mover el mouse o tocar en móviles.
3. **Sección Semillero & Cracks en Acción:**
   - Incorporación del video `img/JUGADOR.mp4` con interfaz deportiva y tarjetas de categorías infantiles.
4. **Pasarela de Fotos & Mística Oficial:**
   - Carrusel interactivo con filtros por categoría (Plantel, Semillero, Sede, Mística) y modal Lightbox de alta resolución.
5. **Spotlight "El Corazón Chequense":**
   - Video institucional con valores formativos y mensaje comunitario.
6. **Diseño y Arquitectura:**
   - Estricta metodología **BEM** (`block__element--modifier`).
   - Sin frameworks de utilidad (cero Tailwind).
   - Design System con variables CSS nativas (`variables.css`).
   - 100% responsivo para móviles, tablets y monitores.

## 🚀 Despliegue en GitHub Pages

Para publicar este repositorio con GitHub Pages:
1. Ir a **Settings** > **Pages** en el repositorio.
2. En **Branch**, seleccionar `main` y la carpeta `/ (root)`.
3. Guardar y la web quedará publicada de manera instantánea.
